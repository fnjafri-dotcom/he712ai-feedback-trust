# HE712AI · Feedback and Trust in AI (sample week)

A draft of one week of HE712AI Foundations for Teaching and Learning (AI), built two ways for co-instructors to compare:

- **Option 1, Interactive** (`interactive.html`): predict, read with a short activity for each reading, the Trust Lab, then reflect.
- **Option 2, D2L page** (`d2l.html`): the same week as one plain page with no scripts.
- **Trust Lab** (`lab.html`): five short gray-zone cases of AI feedback, with no answer key.

Plain HTML with no build step. Answers are kept only in the viewer's browser. All cases are fictional and written for teaching.
