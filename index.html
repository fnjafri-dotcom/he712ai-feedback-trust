Feedback and Trust in AI

The same week built two ways. Both use the same readings, questions, and assignments, and follow the same arc: predict, work through each reading with a desirable difficulty, try the Trust Lab, then reflect on what changed.

Option 1

Interactive module

A guided, step-by-step page. Learners lock in a prediction, sort feedback, estimate results before reading, make a judgment call, run the lab, then see their "before" and "now" side by side. Everything they write is collected into one block to paste into D2L.

Best if: we want the course itself to model active learning with AI. Needs to be hosted (GitHub Pages or uploaded to D2L).

Open Option 1

Option 2

D2L standalone page

One plain page that drops into D2L as a content item. The same activities appear as prompts, with answers hidden under "Check." Learners answer in D2L quizzes, discussions, and assignments. It includes a short text version of the lab.

Best if: we want something simple, familiar, and quick to build for every week.

Open Option 2

Shared by both: the Trust Lab

Five short, gray-zone cases of AI feedback. Learners decide what they'd do with each one, see a case for using it and a case for caution, and bring their choices to the partner discussion. There's no answer key.
